# 🕌 Prayer Time App

A Flutter-based mobile application designed to help users access prayer-related information and features through a simple and user-friendly interface.

## 📱 Project Overview

The Prayer Time App is a Flutter application developed as part of my practical Flutter development work. The application provides users with a structured interface for accessing prayer information.

## ✨ Features

* 🕌 Prayer information and timings
* 📖 Different prayer sections
* 🧭 Qibla-related functionality
* 🔐 Sign In screen
* 🌟 Splash Screen
* 📱 Responsive and user-friendly UI
* ♻️ Reusable widgets and components

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material Design**

## 🚀 Getting Started

### Prerequisites

Make sure you have Flutter installed on your system.

### Installation

1. Clone the repository:

```bash
git clone https://github.com/eihthshamliaqat123-commits/PrayerApp.git
```

2. Navigate to the project directory:

```bash
cd PrayerApp
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
